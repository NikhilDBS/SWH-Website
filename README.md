# Standard Wear House — Website

A premium, custom-designed website for Standard Wear House, a heritage tailoring establishment based in Basavanagudi, Bengaluru (Est. 1972).

## Tech Stack
This project is built using pure vanilla web technologies to ensure maximum performance and longevity:
- **HTML5** (Semantic structure)
- **CSS3** (Custom styling, mobile-first responsive design, modern animations)
- **Vanilla JavaScript** (Navigation, scroll reveals, mobile menu handling)

## Project Structure
The folder structure follows industry-standard deployment guidelines for static websites:
```text
SWH-Website/
├── css/
│   └── style.css       # All styling, including mobile-first responsive rules
├── js/
│   └── main.js         # Interactivity and scroll animations
├── assets/
│   └── img/            # All high-quality image assets
├── index.html          # The main webpage
└── README.md
```

## Running the Project Locally
Because this is a static site with no build step, you can simply double-click `index.html` to open it in any web browser. 

If you want to view it on a local network (e.g., from your phone), you can start a simple local server. For example, using Python (which is pre-installed on most systems):

```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` (or your computer's local IP address, e.g., `http://192.168.1.8:8000`).

## Design Philosophy
This project was designed leveraging the **Antigravity Taste Skill** (`.agents/skills/design-taste/SKILL.md`).
- **Typography**: Uses high-end editorial fonts (`Cormorant Garamond` for headings, `Outfit` for body text).
- **Colors**: Deep luxurious blacks, warm creams, and subtle gold accents.
- **Layout**: Asymmetric, editorial flow with ample whitespace.
- **Animations**: Subtle, performant CSS-based scroll reveals and hover physics.
